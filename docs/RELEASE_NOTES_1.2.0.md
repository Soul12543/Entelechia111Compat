# v1.2.0 — 隐德来希玩法与联机兼容更新

适用《杀戮尖塔 2》v0.111.0 public-beta、原版 Entelechia v1.0.3、BaseLib v3.4.7。联机所有参与者需使用相同版本。

本版本包含玩法调整，更新旧版时请留意：

- 萃血与心烛只有施加者能触发，各玩家独立计算。
- 心烛一次释放全部剩余值；血魔形态每层 +50%、红烛万象 +75% 先相加再计算。100 点心烛同时获得这两个加成时造成 225 点生命流失。
- 血速完整重复打出攻击牌，保留多段和附带效果；追加攻击基础伤害为 35%，向上取整、至少 2 点，自伤仍完整支付。
- 余脉牵引改为 3 费，每次自己回合失血吸取所有敌人 2（3）点生命，升级获得固有。回血与永久最大生命增长均按实际敌方生命损失计算。
- 血宴每回合每 3（2）次攻击牌未格挡命中重复触发；断魂采血在触发萃血且攻击前低血时，同时回能与抽牌。
- 痛觉转化的前 1（2）次有效触发，低血时每次都回 1 能量；血魔形态改为自己回合每次失血获得血速。
- 重盈每场战斗刷新一次；增加可用与触发后减伤状态的说明。
- 更新血盾、心烛仪式、心烛印记、血债清算、血暴、血色横扫、缝合、断续脉搏、血色重构和不死血统的费用、数值或条件及中文描述。开发中的共饮血契已取消。

兼容修复保留并扩展：可选消耗接口、不死血统+零层无效、心烛 Decimal 序列化、余烬跨战斗保存、计数状态同步、Skada 伤害来源及沙耶迟到进化消息处理。

验证：Release 构建 0 警告、0 错误；38/38 本地检查通过，包含原版程序集补丁安装、原生生命损失、JSON/网络数据包往返及中文动态描述。**本轮游戏内加载、双客户端实战、重连和长局尚未实测。** 英文文案尚未全面同步。
